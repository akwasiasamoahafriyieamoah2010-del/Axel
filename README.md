AXEL AI

Your offline AI companion.

AXEL AI is an Android-first offline AI assistant designed to run on devices with 4GB RAM or less.

Project Goals

- Offline-first functionality.
- Lightweight Android application.
- Expressive AI personality.
- Text-based conversations.
- Voice interaction using Android text-to-speech.
- Local conversation history.
- Privacy-focused design.

Development Roadmap

1. Build the Android application.
2. Implement a lightweight local AI model.
3. Add voice interaction.
4. Improve conversation memory.
5. Test performance on low-RAM devices.
6. Build a Windows version.

Important

AXEL AI is under development. Features will be marked complete only after they have been implemented and tested.
